the learner marks a value on a number line: a negative number, a fraction, a decimal, a rounded value or a number between two others. "min" must be below "max". "target" is the correct value, between them. "step" is how far one slider move goes; choose it so the slider can land exactly on "target" (e.g. 0.5 for halves, 0.25 for quarters). "tolerance" is the accepted error, usually 0. "start" is where the marker begins, away from "target". Give 1–4 "points" [{value, label}] as reference marks; never mark "target" itself. In "prompt", say which value to mark (e.g. "Mark −2.5 on the number line."); do not give away where it lies.
